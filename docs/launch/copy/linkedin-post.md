🍴 It's 12:14. Someone drops *"lunch?"* in Slack — and twenty minutes vanish.

Scrolling menus. Pasting links. One poor soul becoming the human spreadsheet who tallies every order and fronts the bill.

The food was never the hard part. The **coordination** is the tax.

So I built **Foody** for the Slack Agent Builder Challenge 🚀 — a group food-ordering agent that lives entirely inside Slack.

Here's the whole thing:

👉 Someone types *"let's eat something"*
🍕 The team taps **emoji reactions** to build one shared basket — the total updates live for everyone
🛒 One tap, and Foody places the order on **Just Eat Takeaway.com**
✅ A clean receipt lands right back in the thread

No app to install. No links to chase. No spreadsheet.

The whole interface is just the **emoji reaction** — the one input device every team already knows how to use.

A few things I'm proud of under the hood:
🩹 A self-healing basket — it reconciles from the *actual* reactions on the message, so a dropped Slack event never desyncs the cart
⚙️ Deterministic by design — fast, predictable, debuggable
🔌 Private by default — runs over Slack Socket Mode, nothing leaves the workspace
